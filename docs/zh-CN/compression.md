# 压缩

| 目标 | 方法 | 800 万像素真实照片实测 |
|---|---|---|
| JPEG 更小，画质不变 | `JPEG(q, JPEGOptions{Optimize: true})`：为该图像单独计算编码表 | 质量 85：983KB → 965KB（减小 1.9%），0.20s，7.3MB |
| JPEG 进一步减小，画质不变 | `JPEGOptions{Progressive: true}`：渐进式编码（含优化编码表） | 983KB → 905KB（减小 7.9%），0.34s，6.6MB |
| JPEG 同等观感下更小（改变像素） | `JPEGOptions{Trellis: true}`：网格量化（mozjpeg 的方法），可与上述两项同时使用 | 7 张真实照片：同等 SSIM 时减小 2.7–10.6%（平均 6.9%），同等 PSNR 时平均减小 6%；3300 万像素耗时增加 0.4s（单线程） |
| PNG 默认更小（无损） | 默认压缩级别为 7（标准库为 6）：Go 的 6 级查找重复数据的能力较弱，7 级在渐变、天空、图标等图像上约小 5 倍，照片小 4–25%；2400 万像素的大图慢 17–70%（单线程），多线程时通过分块压缩弥补。如需标准库的速度，可使用 `PNG(PNGOptions{CompressionLevel: 6})` / `-png-level 6` | 渐变 1200×800：21KB → 4.7KB；2400 万像素 RGB PNG：70.7MB → 53.0MB |
| PNG 大幅减小（有损） | `PNG(PNGOptions{Colors: 256})`：减至最多 256 色，颜色依图像选取，带抖动 | 6474KB → 2653KB（减小 59%），相对原图 39.1dB，0.90s，12.6MB |
| PNG 减色，不抖动 | 另加 `NoDither: true`：文件更小，渐变处出现色带 | 2142KB，40.7dB |
| 压缩至指定大小以内 | `MaxFileSize(n)`：自动选取不超过 n 的最高质量 | 上限 300KB：结果 297KB，0.66s，12MB |
| 转换格式 | `WebP(WebPOptions{Quality: 80})` | PNG 6474KB → WebP 440KB |
| GIF 动画减小 | `Animated()` 的默认行为：所有帧共用一个调色板，自第二帧起仅存储变化的矩形区域，未变化的像素写为透明；颜色不超过 256 种时逐像素不变 | 每帧均完整存储的 8 帧动画（160×120，仅一个小方块移动）：35KB → 5.6KB，画面不变（`FixedPalette` 每帧完整写出，为 55KB） |
| GIF 动画进一步减小（有损） | 另加 `GIF(GIFOptions{Colors: 128, NoDither: true})` 等设置，减少颜色数 | 一个已优化的照片类 GIF 动画（400×533，8 帧，557KB）：不减色 557KB → 556KB（逐像素不变）；128 色 501KB（减小 10%，每帧 39.6dB）；64 色 404KB（减小 27%，34.7dB）；`FixedPalette`（固定调色板加抖动，每帧完整写出）为 814KB |

- **JPEG 的两个选项**不改变任何像素（经 libjpeg 解码验证逐像素相同），文件大小与 libjpeg-turbo 同名选项的结果相差不到 0.04%；算法移植自 libjpeg。不启用这些选项时，输出仍与 Go 标准库逐字节一致。
- **PNG 减色**在同等设置下比 Pillow 的中位切分文件更小、画质更高（上述照片：Pillow 带抖动 2877KB / 34.5dB，不抖动 2309KB / 37.6dB）。透明度予以保留：全透明像素仍为全透明，不透明像素仍为不透明，柔和边缘保留中间透明度。颜色数不超过 `Colors` 的图像原样保留，无损失。
- **与 pngquant 2.17 的对比**（256 色，带抖动；画质为相对原图的 PSNR）：

  | 图像 | 不同颜色数 | goimgtools | pngquant |
  |---|---|---|---|
  | 天空渐变 1920×1080 | 259 | 77.4dB，11.4KB | 63.2dB，4.7KB |
  | 径向渐变 1000×1000 | 302 | 67.4dB，90.5KB | 62.6dB，67.7KB |
  | 天空 + 色块 1920×1080 | 261 | 77.2dB，14.0KB | 63.3dB，6.9KB |
  | 双向渐变 1200×800 | 65536 | 33.8dB，242KB | 34.0dB，221KB |
  | 真实照片 960×540 | 87364 | 40.0dB，185KB | 41.1dB，196KB |

  颜色不超过 16384 种的图像（以渐变、图标、色块为主）按精确颜色选取调色板，画质比 pngquant 高 5–14dB；颜色更多的照片上两者相当。文件大于 pngquant 的部分源于压缩（pngquant 使用 zlib 9 级），使用 `-png-level 9` 时天空渐变为 6.3KB。
- **两个方向均有变化的平滑渐变**（6.5 万种颜色）经带抖动的减色后仍大于全彩，pngquant 亦然；此类图像不抖动（`NoDither`）时仅 8.6KB、36.6dB。命令行选项 `-skip-larger` 在结果不小于原文件时保留原文件（见[命令行](cli.md)）。
- **`MaxFileSize`** 约需编码 6 次，耗时为不限大小时的 4–6 倍；若原质量下已足够小，则只编码一次。质量降至 1 仍无法满足时返回 `ErrFileSize`，须先缩小尺寸。与 `Progressive` 配合时，同样大小下可使用更高的质量。
- 以上各项均须先读取全图，中间数据存入暂存区（超出内存份额时写入临时文件）。GIF 动画须先计算完所有帧：全部帧存入暂存区，输入读取两遍（第一遍统计帧数），按全部帧选取调色板约需 4–5MB 内存；使用 `GIFOptions{FixedPalette: true}` 时边读边写，不存储帧。
- **GIF 动画的抖动**在每帧中独立重新开始，因此未变化区域在各帧中的抖动结果相同，不会闪烁；变化区域（仅存储该部分）依据原始画面判断，不受抖动影响。
