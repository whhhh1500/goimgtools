- **The two JPEG options** leave all pixels unchanged (verified pixel for pixel by decoding with libjpeg). `Optimize` gives files within 0.04% of libjpeg-turbo's option of the same name; its algorithm is ported from libjpeg. `Progressive` chooses its scans as mozjpeg does (`optimize_scans`): of the candidate scans, which are counted while the image is quantized and in one more pass over the stored coefficients, it keeps the cheapest bit depth for the first scans (luminance 0–3, chrominance 0–2 bits left to refinement scans) and the cheapest band split (after coefficient 2, 5, 8, 12 or 18, or none). Its files are therefore smaller than with libjpeg-turbo's fixed script, on which this option was previously within 0.04%. The candidates are counted in parallel with `Threads`; single-threaded, progressive encoding takes 3–19% longer than with the fixed script, with 4 or more threads it is about as fast or faster. Without these options, the output remains byte-for-byte identical to Go's standard library.
- **PNG colour reduction**, under equivalent settings, produces smaller files and higher quality than Pillow's median cut (for the photograph above, Pillow gives 2877KB / 34.5dB with dithering and 2309KB / 37.6dB without). Transparency is preserved: fully transparent pixels remain fully transparent, opaque pixels remain opaque, and soft edges retain their intermediate transparency. An image with no more than `Colors` colours is kept unchanged, without loss.
- **Comparison with pngquant 2.17** (256 colours, with dithering; quality is the PSNR relative to the original):

  | Image | Distinct colours | goimgtools | pngquant |
  |---|---|---|---|
  | Sky gradient 1920×1080 | 259 | 77.4dB, 11.4KB | 63.2dB, 4.7KB |
  | Radial gradient 1000×1000 | 302 | 67.4dB, 90.5KB | 62.6dB, 67.7KB |
  | Sky + colour blocks 1920×1080 | 261 | 77.2dB, 14.0KB | 63.3dB, 6.9KB |
  | Two-way gradient 1200×800 | 65536 | 33.8dB, 242KB | 34.0dB, 221KB |
  | Real photograph 960×540 | 87364 | 40.0dB, 185KB | 41.1dB, 196KB |

  For images with no more than 16384 colours (mainly gradients, icons and colour blocks), the palette is selected from the exact colours, and quality is 5–14dB higher than with pngquant; on photographs with more colours the two are comparable. Where files are larger than pngquant's, the difference is due to compression (pngquant uses zlib level 9); with `-png-level 9` the sky gradient is 6.3KB.
- **Smooth gradients that vary in both directions** (65,000 colours) remain larger than full colour after colour reduction with dithering, as is also the case with pngquant; without dithering (`NoDither`), such an image is only 8.6KB at 36.6dB. The command-line option `-skip-larger` keeps the original file when the result is not smaller than it (see [Command line](cli.md)).
- **`MaxFileSize`** encodes about 6 times, taking 4–6 times as long as without a size limit; if the original quality is already small enough, it encodes only once. If the image still does not fit at quality 1, `ErrFileSize` is returned and the dimensions must be reduced first. Combined with `Progressive`, a higher quality fits within the same size.
- All of the above must read the whole image first; intermediate data is staged (in a temporary file beyond the memory share). For an animated GIF, every frame must be computed first: all frames are staged, the input is read twice (the first pass counts the frames), and selecting the palette from all frames requires about 4–5MB of memory; with `GIFOptions{FixedPalette: true}`, frames are written as they are read and none are stored. An animated WebP is encoded frame by frame; the frame before and the current one are kept in working storage. Peak memory for 1280×720 × 40 frames: lossy 27MB, lossless 53MB (the lossless encoder alone takes 24MB for one such frame); with `MemoryLimit(16 << 20)`, 14MB and 32MB, with the same file.
- **Dithering in animated GIFs** restarts in each frame, so unchanged areas are dithered identically in every frame and do not flicker; the changed region (which alone is stored) is determined from the original image, unaffected by dithering.
